# ActividadS4
Cartelera de películas, uso de Bootstrap
1 Revisá el archivo index.html proporcionado y comprobá que Bootstrap se encuentre correctamente integrado.
2	Organizá el contenido principal de la página dentro de un contenedor de Bootstrap utilizando la clase container.
3	Agregá un título principal para el sitio. Podés utilizar un nombre como Sala 12, CinePlus, MovieSpot o crear uno propio.
4	Incorporá un carrusel de Bootstrap destinado a presentar películas próximas a estrenarse o estrenadas recientemente.
5	El carrusel deberá contener al menos tres películas. Cada elemento deberá incluir una imagen, el título de la película y una breve descripción.
6	Agregá al carrusel controles para avanzar y retroceder, además de indicadores inferiores que permitan seleccionar cada imagen.
7	Incluí en todas las imágenes del carrusel un texto alternativo adecuado mediante el atributo alt.
8	Creá una nueva sección titulada Películas destacadas.
9	Dentro de la sección, incorporá un bloque de seis tarjetas de Bootstrap. Cada tarjeta deberá representar una película diferente.
10	Cada tarjeta deberá incluir una imagen, el título de la película, el género, el año de estreno y una descripción breve.
11	Incorporá en cada tarjeta un botón con un texto como Ver detalles, Ver tráiler o Agregar a favoritos.
12	Organizá las tarjetas mediante el sistema de grilla de Bootstrap. Cada tarjeta deberá ocupar todo el ancho en celulares, la mitad del ancho en tablets y un tercio del ancho en pantallas grandes.
13	Podés utilizar como referencia las clases col-12 col-md-6 col-lg-4 para distribuir las tarjetas de manera responsive.
14	Utilizá al menos dos variantes diferentes de botones de Bootstrap. Por ejemplo: btn-primary, btn-danger, btn-warning o btn-outline-primary.
15	Agregá al final de la página un formulario titulado Recibir novedades de estrenos.
16	El formulario deberá incluir un campo para el nombre, un campo para el correo electrónico y un botón con el texto Suscribirme.
17	Aplicá la clase form-control en los campos del formulario para utilizar la apariencia proporcionada por Bootstrap.
18	Utilizá clases de utilidad de Bootstrap para aplicar márgenes, espacios internos, alineación de textos y colores. Podés utilizar clases como mt-4, mb-3, p-3, text-center o bg-light.
19	Comprobá que el carrusel funcione, que todas las imágenes se visualicen correctamente y que las tarjetas se adapten a celulares, tablets y computadoras.
